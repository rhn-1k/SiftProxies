# SiftProxies

A simple auto updated list of working proxies.
`Updated every 5 hours`

## Download
You could find the list in [good_proxies.txt](good_proxies.txt)

## How it works
collects the proxy list from a huge different sources and compares them to extract the only good ones

> [!WARNING]
> free proxies are untrusted. Don't send passwords or other sensitive data through them.
> proxies can die at any time, so always re-download the list instead of keeping an old copy.

## Status
You could see the current state of the proxies in [status.txt](status.txt)
